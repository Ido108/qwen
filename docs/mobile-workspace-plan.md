# Phone workspace

Use the existing image studio identity: white #ffffff, paper #f6f5fa, text #242134, secondary #716a85, action #684ce6, border #e1dcec. Keep Segoe UI and the current desktop type scale. Phone controls use at least 16 px input text and 44 px touch targets.

The main decision is spatial: one workspace view at a time, with Edit and Result always reachable at the bottom. Keep both views mounted so switching never loses a prompt, photo, job or result. Start a submitted job in Result. Do not force the user to pass all controls before seeing the output. Keep the current view while another queued job completes.

Replace the five horizontally scrolling video tool tabs with one native select on phones. Keep image Create/Swap as two short tabs. Show connection recovery once above the work area. Keep progress in the result and a small status in the bottom switch; remove the duplicate floating queue strip on phones. Keep Queue available in the header.

Use the document for vertical scrolling. Contain horizontal content at its actual source and clip only horizontal page overflow. Preserve browser pinch zoom. Keep output media within the visible phone area. Place secondary details below the media. Test keyboard focus, touch swipes, portrait/landscape, uploads, each video tool, dialogs and live result switching.
